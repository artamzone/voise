Нужно создать локальную Windows-утилиту для голосового ввода текста под названием **Pi Voice**.

## Цель

Я хочу использовать голосовой ввод в терминале pi.dev и других программах Windows.

Сценарий работы:

1. Утилита запускается и работает в фоне.
2. Я удерживаю клавишу `F8`.
3. Пока F8 удерживается — идёт запись с микрофона.
4. Я отпускаю F8.
5. Запись прекращается.
6. Аудио локально распознаётся через `faster-whisper`.
7. Распознанный русский текст автоматически вставляется в активное окно Windows в позицию курсора.
8. Enter автоматически НЕ нажимать.

Пример:

Я удерживаю F8 и говорю:

«Посмотри текущий проект и проверь почему не работает тёмная тема»

После отпускания F8 в активном окне должно появиться:

Посмотри текущий проект и проверь, почему не работает тёмная тема

## Компьютер

Windows 11.

GPU:
NVIDIA GeForce RTX 3080 Ti

CPU:
AMD Ryzen 5 5600X

Для распознавания желательно использовать GPU NVIDIA через CUDA.

## Распознавание

Использовать:

- Python
- faster-whisper
- модель `large-v3-turbo`, если она поддерживается установленной версией
- язык по умолчанию: `ru`
- GPU/CUDA
- подходящий compute_type для RTX 3080 Ti

Модель должна загружаться один раз при запуске программы, а не при каждом нажатии F8.

Первый запуск может скачать модель автоматически.

## Горячая клавиша

Режим Push-to-Talk:

F8 DOWN → начало записи.

F8 UP → остановка записи и запуск распознавания.

Защититься от повторного срабатывания key repeat.

Пока выполняется распознавание предыдущей записи, не запускать второе распознавание одновременно.

## Запись

Использовать микрофон Windows по умолчанию.

Не хранить голосовые записи после успешного распознавания.

Если для обработки нужен временный WAV-файл — удалить его после обработки.

## Вставка текста

После распознавания вставить текст туда, где находится курсор.

Предпочтительная схема:

распознанный текст
→ clipboard
→ Ctrl+V

При этом не нужно автоматически нажимать Enter.

Желательно сохранить прежнее содержимое clipboard и восстановить его после вставки, если это можно сделать надёжно.

Текст должен корректно вставляться на русском языке.

## Безопасность

Вся обработка речи должна происходить локально.

Не использовать облачные Speech-to-Text API.

Не отправлять аудио в OpenAI, Google, Microsoft или другие внешние сервисы.

Не добавлять телеметрию.

pi-voice/

requirements.txt
src/

README должен содержать:

- как выбрать другой микрофон;
- как изменить модель Whisper;
- как переключиться между GPU и CPU.

## Установка

Самостоятельно проверь:

- установленную версию Python;
- доступность NVIDIA GPU;
- CUDA;
- совместимость CUDA/cuDNN с текущей версией faster-whisper/CTranslate2.

Не меняй глобальную конфигурацию Windows или драйвер NVIDIA без необходимости.

Создай отдельное Python virtual environment для проекта.

Не устанавливай зависимости глобально, если это не требуется.

## Проверка

После реализации проведи реальные локальные проверки.

Проверь:

1. запуск программы;
2. обнаружение RTX 3080 Ti;
3. загрузку Whisper на GPU;
4. доступ к микрофону;
5. F8 DOWN;
6. запись;
7. F8 UP;
8. распознавание русского языка;
9. вставку Unicode-текста;
10. повторную диктовку без перезапуска программы;
11. отсутствие оставшихся временных аудиофайлов.

Если автоматическая проверка какого-либо пункта невозможна, скажи мне, что именно я должен проверить вручную.
