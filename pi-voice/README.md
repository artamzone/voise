# Pi Voice

Локальный голосовой ввод для Windows 11: удерживайте **F8**, говорите по-русски, отпустите F8. Текст вставляется через буфер обмена и **Ctrl+V**. **Enter не нажимается**. GUI и автозапуска нет.

## Требования

- 64-битный Python 3.13 (окружение проекта создано на Python 3.13.4).
- Для GPU: NVIDIA RTX 3080 Ti или совместимый CUDA GPU и драйвер с поддержкой CUDA 12.9.
- CTranslate2 4.8.2, faster-whisper 1.2.1; CUDA 12 cuBLAS и cuDNN 9 устанавливаются в `venv` через официальные NVIDIA wheels.
- Микрофон с поддержкой mono/16 кГц через PortAudio (включён в Windows wheel sounddevice).
- Интернет нужен для установки пакетов и первого скачивания модели. Для диктовки после загрузки модели интернет не нужен.

`nvidia-smi` показывает максимальную версию CUDA, которую поддерживает драйвер, а не установленный CUDA Toolkit. Toolkit, системный PATH и драйвер эта утилита не меняет. Если библиотеки не загрузились, сначала выполните диагностику; не устанавливайте системные компоненты вслепую.

## Установка

Команды PowerShell из папки `pi-voice`:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --retries 10 --timeout 120 -r requirements-cuda.txt
```

В этом рабочем каталоге `venv` уже создаётся при реализации. Для CPU без библиотек NVIDIA используйте `-r requirements.txt` и запускайте с `--device cpu`. Зависимости не устанавливаются глобально. Отдельный FFmpeg не нужен: PyAV 16.1.0 поставляется с библиотеками декодирования. Версия зафиксирована: PyAV 19 несовместим с faster-whisper 1.2.1. Полный проверенный набор пакетов записан в `requirements.lock.txt`; для точного повторения окружения используйте `pip install -r requirements.lock.txt` через Python из venv.

## Запуск одной командой

Из `C:\Users\user\voise`:

```powershell
.\pi-voice\start.cmd
```

Из папки проекта: `.\start.cmd`. Активация venv не нужна. Дождитесь `Ready. Hold F8`, затем переключитесь в pi.dev или другую программу. Консоль запуска можно свернуть. Для остановки вернитесь в неё и нажмите Ctrl+C. Второй экземпляр диктовки блокируется.

## Как работает F8

1. F8 DOWN начинает сохранение аудио в оперативной памяти и запоминает активное окно.
2. Повторы клавиши игнорируются. F8 подавляется, чтобы не запускать команды целевой программы.
3. F8 UP прекращает запись и запускает локальное распознавание.
4. Пока идёт распознавание/вставка, новая запись не начинается. Дождитесь `Ready` и нажмите F8 заново.
5. В исходное активное окно отправляется Ctrl+V. Переводы строк в распознанном тексте удаляются; Enter не отправляется.

Микрофонный поток открыт, пока утилита запущена, но аудиоблоки вне удержания F8 не сохраняются. Запись ограничена 120 секундами (`--max-seconds`, диапазон 1–600). После лимита запись обрабатывается автоматически; для следующей записи отпустите F8 и нажмите снова. Записи короче 0.2 секунды пропускаются. VAD отсекает тишину.

## Микрофон

По умолчанию используется вход Windows/PortAudio по умолчанию. Разрешите доступ настольных приложений к микрофону в **Параметры → Конфиденциальность и безопасность → Микрофон**.

```powershell
.\start.cmd --list-microphones
.\start.cmd --microphone 1
.\start.cmd --diagnose
```

Выберите индекс из списка; одно устройство может встречаться в нескольких звуковых API. Индексы могут меняться после подключения оборудования. Если вход не поддерживает 16 кГц, выберите другой вариант того же устройства. Отключение микрофона или потеря аудиоблоков дают ошибку, а не молча испорченную запись.

## Модель, GPU и CPU

По умолчанию: **large-v3-turbo**, язык **ru**, **cuda**, **float16**, GPU 0. Модель загружается один раз и прогревается перед регистрацией F8. Ошибка GPU не вызывает скрытого перехода на CPU.

```powershell
.\start.cmd --model large-v3-turbo --device cuda --compute-type float16
.\start.cmd --device cpu --compute-type int8
.\start.cmd --model small --device cpu
.\start.cmd --language en
.\start.cmd --check-model
```

Модель автоматически скачивается из Hugging Face (алиас `mobiuslabsgmbh/faster-whisper-large-v3-turbo`, сейчас перенаправляется на `dropbox-dash/faster-whisper-large-v3-turbo`) в `pi-voice\models\`, независимо от текущего рабочего каталога. Папка содержит cache snapshots/blobs; не удаляйте её при работающей программе. Предупреждение Hugging Face о недоступных symlinks не мешает работе: cache использует копии; включать Developer Mode или запускать от администратора не нужно. Для другого каталога используйте `--model-dir D:\WhisperModels`; для уже конвертированной CTranslate2-модели — `--model D:\Models\whisper-turbo`.

После первого успешного запуска можно запретить скачивание:

```powershell
.\start.cmd --offline
```

## Буфер обмена и ограничения вставки

По умолчанию текст остаётся в буфере обмена. Автоматическое восстановление отключено: Windows не подтверждает, что целевое приложение уже прочитало Ctrl+V. Так текст можно вставить вручную, если приложение отвергло сочетание.

`--restore-clipboard` включает **best-effort** восстановление прежнего обычного текста через 0.5 секунды, только если буфер не изменён другой программой. Изображения, файлы, HTML и другие сложные форматы не восстанавливаются; медленное приложение может прочитать буфер позже. Для надёжной вставки оставьте настройку выключенной.

Не меняйте окно/поле ввода до вставки и отпустите Ctrl/Shift/Alt/Win. Если окно сменилось или модификаторы не отпущены, автоматической вставки не будет: результат останется в буфере для ручного Ctrl+V. Смена поля внутри того же окна не отслеживается.

В целевой программе должен работать **Ctrl+V** (Windows Terminal/Tabby — проверьте настройки). Windows может блокировать ввод в приложение с более высокими правами; запускайте обе программы с одинаковым уровнем прав, предпочтительно без администратора. F8 глобально зарезервирована, пока работает Pi Voice.

## Приватность

- STT работает локально, облачных Speech-to-Text API нет.
- Микрофонное аудио — массив float32 в RAM; WAV-файлы при диктовке не создаются.
- Аудио и расшифровки не сохраняются в логах. Лог содержит статусы, ошибки, длительность и число символов.
- Телеметрия Hugging Face отключена. Сеть используется для скачивания зависимостей/весов; `--offline` запрещает скачивание модели.
- Текст передаётся системному clipboard: история/синхронизация clipboard и целевое приложение подчиняются настройкам Windows, а не этой утилиты.

## Проверки

Из папки проекта:

```powershell
$env:PYTHONPATH = "$PWD\src"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m compileall -q src tests
.\.venv\Scripts\python.exe -m pip check
.\start.cmd --diagnose
.\start.cmd --check-model --offline
.\.venv\Scripts\python.exe tests\local_smoke.py
```

`local_smoke.py` использует **локальный русский SAPI-голос** и временный WAV, удаляемый после декодирования. Загружает модель на GPU, измеряет три распознавания, открывает отдельное тестовое текстовое окно и проверяет два цикла программно отправленных F8 и Unicode Ctrl+V без Enter. На время теста окно получает фокус и буфер обмена заменяется тестовым текстом; прежний обычный текст восстанавливается, сложные форматы — нет. Не трогайте клавиатуру/окно во время теста. Это диагностическое окно, не GUI утилиты.

Результаты фактических проверок — в [CHECKS.md](CHECKS.md).

**Ручная проверка:** после `Ready` переключитесь в pi.dev, удерживайте физическую F8, произнесите «Посмотри текущий проект и проверь, почему не работает тёмная тема», отпустите F8. Убедитесь, что текст появился у курсора, команда не отправлена; повторите без перезапуска. Автоматические тесты с синтетической речью не подтверждают качество именно вашего микрофона, физическую F8 и вставку в настройки вашего терминала.
